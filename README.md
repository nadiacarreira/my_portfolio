# MyPortfolio

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 19.2.7.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Code scaffolding

Angular CLI includes powerful code scaffolding tools. To generate a new component, run:

```bash
ng generate component component-name
```

For a complete list of available schematics (such as `components`, `directives`, or `pipes`), run:

```bash
ng generate --help
```

## Building

To build the project run:

```bash
ng build
```

This will compile your project and store the build artifacts in the `dist/` directory. By default, the production build optimizes your application for performance and speed.

## Running unit tests

To execute unit tests with the [Karma](https://karma-runner.github.io) test runner, use the following command:

```bash
ng test
```

## Running end-to-end tests

For end-to-end (e2e) testing, run:

```bash
ng e2e
```

Angular CLI does not come with an end-to-end testing framework by default. You can choose one that suits your needs.

# My Portfolio

In this project, I will be creating my UX/UI portfolio to showcase my work in UX research, UI design, and overall design solutions. The portfolio will include various projects, demonstrating my approach to user experience research, user interface design, and the development of effective design solutions. It will serve as a comprehensive representation of my skills, methodology, and design thinking process.

# TECNOLOGIES USED

- **Angular**: The main framework for building the web application.
- **Bootstrap**: For responsive design and ready-to-use components.
- **Angular Material**: For ready-to-use UI components with Material Design.
- **SCSS**: For advanced and customized stylesheets.
- **ESLint**: To maintain clean and high-quality code.
